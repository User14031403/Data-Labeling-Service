# AI Data Labeling Service - Frontend

This is the frontend-only deployment of the AI Data Labeling Service for GitHub Pages.

## About

This is a **static frontend** of the AI Data Labeling Service, a comprehensive platform for automating annotation of text, image, and audio datasets for machine learning workflows.

**Note:** This is a frontend-only version. The full-stack application with backend and database is available at:
- **Live Demo:** https://datalabels-wkcjgf4a.manus.space
- **Full Repository:** https://github.com/User14031403/Data-Labeling-Service

## Features Displayed

- **Dashboard UI** - Dataset management interface
- **Taxonomy Management** - Label category definitions
- **Labeling Tasks** - Task creation and monitoring interface
- **Batch API Documentation** - REST API reference
- **Results Viewer** - Labeled data display and export

## Limitations

This is a **static frontend** and does not include:
- Backend API integration
- Database connectivity
- AI labeling engine
- File uploads
- Real data processing

For full functionality with AI-powered labeling, use the live demo at https://datalabels-wkcjgf4a.manus.space
